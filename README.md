# Sales Agent Extension Suite

A customer-safe, plain-English product overview and enablement package.

- Web package version: `0.7.0`
- Sales Agent Extension Suite candidate: `1.0.0`

The web package version tracks the public content experience. The suite version
tracks the deployable product candidate; they are intentionally separate.

- `index.html` explains the everyday value for sellers, managers, account teams, and operations.
- `enablement.html` shows how to run a useful evaluation and decide whether to continue.
- `technical-reference.html` preserves the detailed capability, proof, architecture, testing, and deployment reference for implementers.
- `privacy.html` and `terms.html` state the V1 runtime, data, qualification, and use boundaries.

## Current state

V1 packages all 137 governed workflows into one managed Copilot Studio solution and seven connector-free Cowork packages. The managed solution passed clean import, native Dataverse connection binding, publish, and synchronization checks; the Cowork packages passed 413 of 413 package checks. One bounded opportunity-context tool is implemented. The remaining workflows require customer-specific host and data-path qualification before production-shaped use.

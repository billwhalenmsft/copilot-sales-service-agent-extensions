# Copilot Sales and Service Agent Extensions

Customer-safe capability and installation overview for the extension family.

The page now leads with the portfolio's ten capability families, concrete Sales,
Service, Field Service, and Cowork experiences, a sanitized specimen of the
host-qualified D365 Sales result, and a five-gate visual validation roadmap.
The detailed execution matrix remains private in the sibling governance folder.

## Current release

- **Sales Evidence for D365 v1.0.7**
- Read-only, human-review-required opportunity next-step draft
- Qualified in first-party Sales with three direct citations, telemetry, and
  zero source-record changes

## Important boundaries

- This package is a product information page, not the deployable Microsoft 365
  app package.
- Customer packages are generated per tenant because their application IDs,
  OAuth registration, backend URL, and Dynamics environment differ.
- Cowork has a separate validated `1.0.0` package, isolated read-only MCP
  endpoint, OAuth registration, and private demo-admin install. A delegated
  Cowork conversation with live D365 citations remains the host-qualification
  gate. Customer Service, Field Service, ERP, Salesforce, and write workflows
  remain independently gated and are not claimed as shipped in Sales v1.0.7.
- The page contains no customer data, credentials, tenant IDs, private links,
  or internal account information.

Installation path

Choose one Microsoft-hosted path and start with a bounded pilot

The release contains eight directly installable artifacts: one managed Copilot Studio solution and seven alternative Cowork packages. The package build requires no tenant changes; import, connection binding, publication, and user assignment remain explicit customer-admin actions.

  1. Choose the host.
    Use the managed Copilot Studio solution for one governed agent, or install the seven Cowork packages for skills-only use.
  2. Confirm prerequisites.
    Identify the target environment, customer admin, one to three pilot users, required licenses, and approved records.
  3. Install natively.
    Import and bind the Dataverse connection in Copilot Studio, or install the connector-free Cowork ZIPs. No custom backend is provisioned.
  4. Assign narrowly.
    Publish or enable the package only for the approved pilot audience, not the whole organization.
  5. Prove the workflow.
    Run fresh conversations, open the cited records, test denied and malformed requests, and compare records before and after.
  6. Decide and expand.
    Continue, revise, or remove the package. Qualify each additional live data path or action before claiming it ready.

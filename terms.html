Sales Agent Extension Suite V1

Terms of use

Terms for evaluating and operating the customer-installable Sales Agent Extension Suite accelerator.

Evaluation accelerator: V1 is an accelerator for governed customer pilots. It is not a Microsoft product entitlement, Marketplace certification, production SLA, or promise that every workflow is qualified for every tenant.

Permitted use

Use the packages in an authorized Microsoft 365 and Power Platform tenant for internal evaluation, controlled pilots, and approved implementation work. Administrators are responsible for tenant policy, licensing, capacity, data residency, connector approval, permissions, audience assignment, and support ownership.

Installation

The default Copilot Studio deployment imports one managed solution. The alternative Copilot Cowork deployment installs seven skills-only packages. Neither path requires a customer-managed Azure Function, custom API, or external MCP runtime.

Customer configuration

Live data access depends on native tools and connections selected by the customer. Customers must review each connection, assign least privilege, authorize test records, and validate results and effects before expanding an audience.

Qualification

Package validation proves structural compliance, not business accuracy or live host qualification. A workflow is ready for production-shaped use only when its exact host, provider, citation, negative-path, metering, and effect tests pass in the target environment.

External effects

No conversational request may bypass approval requirements. Writes, sends, schedules, assignments, publications, purchases, deployments, and destructive actions require the owning system's controls and a verifiable receipt.

No warranty

The accelerator is provided for evaluation and implementation planning without warranties or guarantees. Validate all outputs before relying on them for customer, commercial, operational, safety, legal, financial, or regulatory decisions.

Removal

Disable assigned audiences before uninstalling. Remove only the managed solution or Cowork package IDs recorded by the installation receipt, and preserve any customer-owned records or shared connections.
